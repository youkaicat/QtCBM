

# QtCBM

Simple [Dot-probe task](https://en.wikipedia.org/wiki/Dot-probe_paradigm) implementation for [attention retraining](https://en.wikipedia.org/wiki/Attentional_retraining) in [cognitive bias modification therapy](https://en.wikipedia.org/wiki/Cognitive_bias_modification).

## Building

This is a Qt C++ application. Open the project directory in [Qt Creator](https://www.qt.io/product/development-tools) to build and run it, or compile it using your preferred build system with Qt 5/6. Ensure the `QtCharts` module is included for the delay visualization charts.
